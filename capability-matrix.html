Foundational Principles

The Five Laws — Bar for Bar

1967
Conway's Law
Mel Conway
"Read the boundaries before writing the code. Four services. Four teams. One developer designed it that way."
1974
Separation of Concerns
Edsger Dijkstra
"Kept every concern in isolation. No crossover. No shortcuts. The database has never seen HTTP."
1975
Principle of Least Privilege
Jerome Saltzer
"Locked the vault. One key. One service. The other three don't know the database exists."
1994
Fallacies of Distributed Computing
Peter Deutsch
"The network lies. So I built probes every 30 seconds that catch it before the user does."
2003
Single Responsibility Principle
Robert C. Martin
"One job each. Auth ships alone. API ships alone. Web ships alone. Change one — touch nothing else."

Conway read the boards and drew four boundaries.
Dijkstra kept them isolated — no service crosses the line.
Saltzer locked the vault — one key, one door, least privilege.
Deutsch said the network lies — so I built probes that don't.
Martin said one job each — so each service ships alone.
